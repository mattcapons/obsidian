Consider a dynamic table data structure for storing a variable number of elements in memory.
When created, the table has space for storing only one element, and pushing one element in the
table has a constant cost.

If the table is full, twice the size of the original table is allocated to a new table and all elements of
the original table are copied in the new table. The cost for allocating one unit of memory  is
constant.

Compute the real cost for inserting n elements into a new-allocated table (having an  initial
capacity for storing only one element) and determine the amortized cost for the allocating the
same number of elements using one of the methods seen during the course.
